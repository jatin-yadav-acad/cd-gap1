1. Biological Premise & Minimax Game Formulation SDG 3 TARGET

The Clinical Crisis: Metallo-β-lactamase NDM-1 (PDB: 3SPU) hydrolyzes carbapenems ("antibiotics of last resort"). Traditional virtual screening on static crystal structures yields leads that rapidly fail against single-point active-site loop mutations (Met67 on L3 loop; Lys211, Asn220 on L10 loop).

Two-Player Zero-Sum Game Formulation Minimax Optimization
V*(St) = maxChemist (W) minPathogen (B) E [ R(Sterminal) ]
Pathogen Agent (Black):
ESM-2 (650M) evaluates non-synonymous mutations:
ΔFitness = log P(mut) - log P(wt) > -1.5
Prunes lethal mutations that disrupt the fold.
Chemist Agent (White):
14B Reasoning Policy within MCTS-UCT maximizes:
R = -w₁(ΔG) + w₂(QED) - w₃(SAScore) + RZn
w₁=1.0, w₂=2.5, w₃=0.5, RZn=+3.5 bonus.
The Biological Checkmate: While loop perimeters mutate freely, the catalytic zinc coordination shell (His120, His122, Asp124, His189, Cys208, His250) has 0% mutational viability. Bridging this shell creates an inescapable evolutionary trap.
